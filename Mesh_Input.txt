i -> horizontal
j -> vertical

o---------o----------o-----------------o
|         |          |                 | 
|         | obstacle |                 | y2 (M2)
|         |          |                 |
o---------o----------o-----------------o
|         |          |                 |
|         |          |                 | y1 (M1)
|         |          |                 |
o---------o----------o-----------------o
  x1 (N1)   x2 (N2)        x3 (N3)

x1: 1st horizontal interval
x2: 2nd horizontal interval
x3: 3rd horizontal interval
y1: 1st vertical interval
y2: 2nd vertical interval
y3: 3rd vertical interval

For the case without the obstacle, only one region is considered, 
and only the parameters corresponding to x1 & y1 are used to discretize the domain.

----------- DISCRETIZATION PARAMETERS -----------

Minimum horizontal element size 'hx_min' (m):
0.1
Maximum horizontal element size for x1 'hx_max1' (m):
1
Maximum horizontal element size for x2 'hx_max2' (m):
1
Maximum horizontal element size for x3 'hx_max3' (m):
1
Minimum vertical element size 'hy_min' (m):
0.1
Maximum vertical element size for y1 'hy_max1' (m):
1
Maximum vertical element size for y2 'hy_max2' (m):
1
Maximum vertical element size for y3 'hy_max3' (m):
1

Transition smoothness parameter along x1 'alpha_x1':
0.5
Transition smoothness parameter along x2 'alpha_x2':
0
Transition smoothness parameter along x3 'alpha_x3':
0
Transition smoothness parameter along y1 'alpha_y1':
0.5
Transition smoothness parameter along y2 'alpha_y2':
0
Transition smoothness parameter along y3 'alpha_y3':
0
-> To set uniform discretization for a desired region, set its corresponding alpha=0
-> The h used will be the minimum of hx_min and hy_min, and will be reduced if necessary
